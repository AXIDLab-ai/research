# 연구 실행 명세

## 질문과 기여 범위

평가기간과 성과 연동 배분강도가 운영사의 기업 선별·지원에 미치는 상호작용을 연구한다. 업종별 매출 기준 도달률의 차이만으로 정책 실패를 선언하지 않는다. 사업화 지연과 장기 잠재력의 상관, 운영사의 적응, 지원 효과를 바꿔 정책 순위가 유지되거나 바뀌는 조건을 제시한다.

기존 성과평가·하이브리드 VC·장기 성장 연구를 대체하는 문헌 검증은 아니다. 논문 기여는 향후 실제 결과와 기존 문헌의 비교로 확정해야 한다. RP/JBV 게재 가능성이나 새로운 기여의 성립을 코드 구현만으로 보장하지 않는다.

## 사후적 분석 방지와 동결

기존 자료와 일부 결과를 이미 탐색했다. 현재 설계는 이론에 근거한 구조와 데이터 기반 nuisance 보정을 결합한 하이브리드 설계이다. 새 날짜를 붙여 이전 결과를 사전 가설로 바꾸지 않는다.

1. D0: 질문, 정보집합, 메커니즘, 정책 격자, 주결과, 영효과 세계, 제외 기준 동결.
2. E0–E2: 데이터 감사와 모형 적합성 진단. 정책 우위는 보정 목표에서 제외.
3. D1: 허용오차, 모수 집합, 반복수, 난수, 코드·입력 해시 동결.
4. E3: 정책 비교. 이후 변경은 탐색적 확장으로 별도 버전·결과 보존.

## 실험 지도

| 실험 | 구현 | 해석 |
|---|---|---|
| E0 자료 감사 | `prepare`, `audit`; 명세·결측·폐업·0·연도·단위 | 관측 데이터의 범위 |
| E1 고정경로 재평가 | `replay`; 과거 관측 성과에 평가와 가상 추천권 적용 | 성과 개선 추정이 아님 |
| E2 다중 패턴 보정 | `calibrate`, `diagnose` | 자료와 양립하는 모수 집합 |
| E3 정책 격자 | `run --family worlds --grid` | 세계 27 × 정책 37 × 허용 집합 × 반복 |
| E4 메커니즘 제거 | `run --family ablation` | 적응·능력 차이·지원·희석·시차·관측의 역할 |
| E5 민감도 | `run --family sensitivity` 또는 `lhs` | 조건별 순위 변화; LHS를 Sobol 지수라고 부르지 않음 |
| E6 정보 개선 | `run --family information` | 속도·신호·기록 개선의 조건부 성과와 후회 변화 |
| E7 선택 확장 | `rl` | 유한 행동 tabular Q; 주분석과 분리 |

### E0–E1

원자료는 로컬 `data_private/` 또는 업로드한 사용자 세션에서만 처리한다. E1은 사후 조사기록의 고정경로 실험이며 정부가 실제로 같은 정보를 갖고 있었다고 주장하지 않는다. 실제 사업화 속도가 없어 E1에서 차등속도 정책은 실행하지 않는다. 익명 운영사별 E1 결과도 재식별 가능성이 있어 공개 원고 첨부 전 공개 범위를 별도로 결정한다.

### E2: 보정과 이전 진단

- 자료 추정: 초기 구성, 초기 상태, 축소 전이행렬, 조건부 공동 재무은행, 관측 누락률.
- nuisance 탐색: 매출·흑자·퇴출 destination intercepts [−1.5,1.5], age와 duration coefficients [−0.15,0.15]. Latin hypercube로 시작점을 고정한다.
- 미식별 구조: q–지연 상관, 행동 적응, 지원 효과, 능력 차이, 후보풀 등. 구조 세계별 nuisance만 재보정한다.
- loss: 패턴별 (sim−data)/scale의 제곱을 패턴군 내부에서 평균, 패턴군 사이를 동일 가중. 재무 패턴은 asinh(value/threshold) 분위수. 최소 셀 n=10. 상태·결측·0 scale=.15, 폐업=.08, 전이=.2, 변환재무=.5. 이 척도는 임의 표준오차가 아니라 명시된 허용 척도다.
- 각 패턴군 RMSE가 tolerance 이하인 모든 집합을 남긴다. 디폴트 tolerance=1.5는 연구자가 D1에서 검토·동결할 작업값이다. 적합성을 보장하지 않는다. 시뮬레이션에 필요한 패턴이 사라지면 큰 손실을 부과한다.
- 허용 집합이 없으면 E3의 보정 실행은 중단한다. 가장 작은 손실을 자동 채택하지 않는다. 변경 사유와 버전을 남긴다.
- ≤2019 h0–2 보정, ≤2019 h3–5와 2020–22 h0–2, ≤2016 h6–8 진단. 이미 살펴본 표본이므로 독립 확증 검증이 아니다.

### E3: 기본 정책·세계

공통 h=2/3/5와 관측 속도별 h=2/3/5. λ=.25/.5/1 × ε=0/.1/.25를 각각 교차한다. λ=0 중복을 하나로 묶어 총 37개. 별도 화면 preset은 직관적인 일부 비교와 동일배분 benchmark를 포함한다.

구조 세계는 ρ∈{−.5,0,.5}, α∈{0,1,2}, θ∈{0,.25,.5}의 27개. 구조 세계별 허용 모수 집합은 모든 정책에 동일 적용한다. 정책별로 유리한 모수를 다시 맞추지 않는다.

반복 간 독립, 정책 간 공통 난수. 파일럿 30회로 짝지은 차이의 표준편차를 추정한 뒤 `precision` 명령으로 요구 반복수를 계산한다. 작업 범위 200–2000, 목표 반폭은 연구자가 결과 열람 전에 정한다. 1.96 근사는 계산오차 계획용이며 모든 불확실성의 신뢰구간이 아니다.

### E4–E6: 주분석과 구분

E4와 E6 및 OAT는 기준 세계의 허용 nuisance를 고정해 메커니즘을 바꾸는 실행을 지원한다. 바뀐 구조를 데이터에 다시 보정하는 분석은 별도 `calibrate --family ...`로 저장하고 주분석과 섞지 않는다. E4는 관측자료의 인과적 placebo가 아니다.

OAT: H=5/10, 초기 이력 0/10, unknown credit 0/1, observed-only, 속도 오분류, 후보비율, 운영사 수, 능력상관, tail entry, AR 지속성, emission family, β, prior, 지원기간, 할인율, 업종비중과 평가 지표. 추가 매출 기준 500/1000/2000은 `--set`으로 번들을 다시 만들어 각 기준별 재보정한다. 동시0 처리는 `--strict-zero` 유무로 각각 실행한다.

E6은 정보 개선 시 성과·후회가 얼마나 달라지는지 보여준다. 정보획득 비용·세계별 확률·후속 데이터생성분포가 없으므로 EVSI를 계산했다고 부르지 않는다. 지원활동의 실제 관측자료는 추가 수집 대상이며 현재의 정보 실험에 없는 사실을 추정하지 않는다.

### 불확실성과 보고

1. 계산 불확실성: 동일 세계·모수 집합 안의 반복 및 paired MCSE.
2. 자료 불확실성: 운영사 단위 cluster bootstrap. `--bootstrap 0`, `1`, …을 보정과 본실험에 똑같이 적용하고 결과를 별도 저장한다. 재표본마다 재보정한다.
3. 모수 적합성: 모든 허용 집합의 결과 범위. 일부 좋은 정책순위만 선택하지 않는다.
4. 구조 불확실성: 27개 세계와 구조 대안. 시나리오 비중은 확률이 아니다.
5. 규범 선택: 할인율·unknown credit·목적함수. 별도 표로 보고한다.

보고서는 두 주목적의 Pareto 집합, 목적별 regret와 minimax regret를 계산한다. 단일 종합 순위로 목적의 충돌을 숨기지 않는다. 퇴출·집중·지연형 비중·latent quality를 보조표에 둔다. 실패한 작업과 불완전 비교 블록을 기록하고 완전한 정책 집합을 가진 블록으로만 paired 비교한다.

## 한계와 필수 후속 단계

지원 효과·행동·진짜 사업화 속도는 식별되지 않는다. 전이행렬은 선택·생존·결측의 영향을 받는다. 초기 3개년 재무은행의 장기 외삽 및 단순 survey mask가 중요 구조 가정이다. 폐업과 성공적 M&A 등 모든 경제적 퇴출의 구분 자료가 완전하지 않다. 실제 정책의 복잡한 최종평가 규정을 복제하지 않는다.

구현 검증, 합성자료 회복 실험, 경험 패턴 진단, 연구 규모 실행은 별도로 수행하고 결과를 기록해야 한다. 현재 코드 제공은 그것들이 통과했다는 선언이 아니다. 미래 독립 자료에 대한 외부 타당성은 현 자료로 해결할 수 없다.
